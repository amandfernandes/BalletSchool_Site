Este projeto foi desenvolvido como parte da disciplina de **Design e UX** e é um redesign do website para a **Black Swan**, uma escola fictícia de ballet inspirada no personagem da peça *O Lago dos Cisnes*. Inicialmente, o projeto foi desenvolvido com foco na criação de uma interface visual atraente e uma experiência de usuário intuitiva, utilizando **HTML** e **CSS**.
Posteriormente, visando aprimorar e expandir as funcionalidades do projeto, foi incorporado o uso de **TypeScript**, permitindo explorar conceitos de desenvolvimento web moderno e fortalecer habilidades técnicas. 

## Visão Geral

O objetivo principal do projeto foi criar um website que representasse a escola fictícia **Black Swan** de forma atraente, utilizando princípios de **Design e UX** e incorporando as melhores práticas de **desenvolvimento web**. O design foi cuidadosamente elaborado para refletir o tema da peça *Black Swan*, enquanto a experiência do usuário foi otimizada para garantir facilidade de navegação.

### Objetivos do Design:
- **Interface Visual:** Criar um design elegante e sofisticado, alinhado à temática da peça *Black Swan*.
- **Experiência do Usuário (UX):** Garantir uma navegação intuitiva e fluída entre as páginas, com uma estrutura simples e fácil de entender.
- **Aprimoramento Técnico:** Integrar **TypeScript** para melhorar a funcionalidade e garantir maior segurança no código.

## Funcionalidades

O website oferece diversas funcionalidades que garantem uma experiência interativa e informativa para os usuários:

### 1. **Página Inicial**
   - Exibe uma visão geral da escola **Black Swan**, com destaques sobre os próximos espetáculos, as aulas disponíveis, professores em destaque e um formulário de inscrição para a newsletter.
   - **Carrossel de Espetáculos:** Mostra os próximos eventos com botões de navegação para facilitar a visualização.

### 2. **História**
   - Apresenta a história da escola **Black Swan** em formato de linha do tempo interativa.
   - Inclui **imagens** e **descrições** dos principais marcos da escola, com foco em momentos importantes.

### 3. **Professores**
   - Exibe informações sobre os **instrutores** da escola, incluindo:
     - Foto do professor.
     - Nome completo.
     - Breve biografia profissional.
   - Funcionalidade dinâmica com dados gerados automaticamente via **TypeScript**.

### 4. **Galeria**
   - Apresenta uma coleção de fotos de **espetáculos** e **eventos** realizados pela escola.
   - **Modal de Imagem:** Ao clicar em uma imagem, ela abre em uma janela modal para visualização em tamanho maior, proporcionando uma experiência mais interativa.

### 5. **Página de Aulas de Ballet**
   - Fornece informações detalhadas sobre as aulas de ballet oferecidas pela escola, incluindo:
     - **Áreas de ensino**.
     - **Abordagem educacional**.
     - Formulário de inscrição para audições de novos alunos.
   
### 6. **Navegação**
   - O site possui uma **navegação consistente** e intuitiva em todas as suas páginas.
   - Um **menu de navegação** dinâmico que é gerado pelo **TypeScript**, permitindo fácil acesso às diferentes seções do site.
## Técnologias Utilizadas

O projeto utiliza uma combinação de **HTML**, **CSS**, e **TypeScript** para proporcionar um site visualmente atraente e funcional.

### **1. HTML**
- Serve como a estrutura do site, com cada página organizada em documentos HTML separados.
- Os scripts TypeScript são compilados para JavaScript e referenciados nas páginas HTML, mantendo o código modular.

### **2. CSS**
   - Estilo, inspirado no tema Cisne Negro, utiliza uma paleta de cores em preto e branco e fontes elegantes

### **3. TypeScript**
- **Funcionalidades Interativas**: O TypeScript é usado para aprimorar a **interatividade** e a **dinâmica** do site, além de oferecer **maior segurança de tipos** e facilitar a **manutenção** do código.
- **Geração Dinâmica de Conteúdo**: O TypeScript é responsável por gerar conteúdo **dinâmico** nas páginas do site, como:
   - O **menu de navegação**, que é gerado de forma programática.
   - A **lista de professores**, exibindo **nome**, **foto** e **biografia** de forma automática a partir de dados organizados.
   - A **seção de espetáculos**, onde os **próximos eventos** são exibidos dinamicamente, com a possibilidade de adicionar ou remover eventos facilmente.
- **Modal de Imagem**: O TypeScript também gerencia a funcionalidade de **modal de imagem** na galeria, permitindo exibir fotos em **tamanho maior** ao clicar nelas.
- **Carrossel de Espetáculos**: Utilizando TypeScript, o carrossel de espetáculos na página inicial exibe **eventos futuros** e permite a **navegação entre as imagens**.
- **Integração com HTML**: O TypeScript é **compilado para JavaScript** e os scripts gerados são integrados aos documentos **HTML** através dos caminhos para os arquivos compilados.
