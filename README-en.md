This project was developed as part of the **Design and UX** course and is a redesign of the website for **Black Swan**, a fictional ballet school inspired by the character from the play *Swan Lake*. Initially, the project focused on creating an attractive visual interface and an intuitive user experience, using **HTML** and **CSS**.  
Later, aiming to enhance and expand the project's functionalities, **TypeScript** was incorporated, allowing the exploration of modern web development concepts and strengthening technical skills.  

## Overview  

The primary goal of the project was to create a website that represents the fictional **Black Swan** school in an appealing way, applying **Design and UX** principles and incorporating best practices in **web development**. The design was carefully crafted to reflect the theme of the play *Swan Lake*, while the user experience was optimized to ensure easy navigation.  

### Design Goals:  
- **Visual Interface:** Create an elegant and sophisticated design aligned with the theme of the play *Swan Lake*.  
- **User Experience (UX):** Ensure intuitive and seamless navigation between pages, with a simple and easy-to-understand structure.  
- **Technical Enhancement:** Integrate **TypeScript** to improve functionality and ensure greater code safety.  

## Features  

The website offers several features that provide an interactive and informative experience for users:  

### 1. **Home Page**  
   - Displays an overview of the **Black Swan** school, highlighting upcoming performances, available classes, featured instructors, and a newsletter subscription form.  
   - **Performance Carousel:** Showcases upcoming events with navigation buttons for easy viewing.  

### 2. **History**  
   - Presents the history of the **Black Swan** school in an interactive timeline format.  
   - Includes **images** and **descriptions** of the school's key milestones, focusing on important moments.  

### 3. **Instructors**  
   - Provides information about the school's **instructors**, including:  
     - Instructor's photo.  
     - Full name.  
     - Brief professional biography.  
   - Dynamic functionality with data automatically generated via **TypeScript**.  

### 4. **Gallery**  
   - Showcases a collection of photos from **performances** and **events** hosted by the school.  
   - **Image Modal:** Clicking on an image opens it in a modal window for larger viewing, offering a more interactive experience.  

### 5. **Ballet Classes Page**  
   - Provides detailed information about the ballet classes offered by the school, including:  
     - **Teaching areas**.  
     - **Educational approach**.  
     - Registration form for new student auditions.  

### 6. **Navigation**  
   - The site features **consistent and intuitive navigation** across all pages.  
   - A **dynamic navigation menu** generated by **TypeScript**, allowing easy access to different sections of the site.  

## Technologies Used  

The project uses a combination of **HTML**, **CSS**, and **TypeScript** to deliver a visually appealing and functional site.  

### **1. HTML**  
- Serves as the site's structure, with each page organized in separate HTML documents.  
- TypeScript scripts are compiled to JavaScript and referenced in the HTML pages, keeping the code modular.  

### **2. CSS**  
   - Styling, inspired by the Black Swan theme, uses a black-and-white color palette and elegant fonts.  

### **3. TypeScript**  
- **Interactive Features**: TypeScript is used to enhance the site's **interactivity** and **dynamics**, while also providing **type safety** and making the code easier to maintain.  
- **Dynamic Content Generation**: TypeScript is responsible for generating **dynamic content** on the site's pages, such as:  
   - The **navigation menu**, programmatically generated.  
   - The **instructors' list**, automatically displaying **name**, **photo**, and **biography** from organized data.  
   - The **performances section**, where **upcoming events** are dynamically displayed, with the ability to easily add or remove events.  
- **Image Modal**: TypeScript also manages the **image modal** functionality in the gallery, allowing users to view photos in **larger sizes** by clicking on them.  
- **Performance Carousel**: Using TypeScript, the performance carousel on the homepage displays **future events** and allows users to **navigate between images**.  
- **HTML Integration**: TypeScript is **compiled into JavaScript**, and the generated scripts are integrated into the **HTML** documents through paths to the compiled files.  

## Installation  

1. Clone this repository:  
   ```bash  
   git clone https://github.com/amandfernandes/BalletSchool_Site.git  
   ```  
2. Navigate to the project directory:  
   ```bash  
   cd BalletSchool_Site  
   ```  
3. Install dependencies:  
   ```bash  
   npm install  
   ```  
4. Start the project:  
   ```bash  
   npm run server  
   ```
